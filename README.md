# SurrounDead Cheat

Simple external cheat for **SurrounDead**, written in Python using `ctypes` and `PyQt5`.

## Features

* God mode for:

  * Health
  * Stamina
  * Hunger
  * Water
* Global **INSERT** key to hide / show

---

## Requirements

* Windows
* Python 3
* PyQt5

```bash
pip install PyQt5
```
